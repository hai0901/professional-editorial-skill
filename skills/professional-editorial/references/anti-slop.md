# Anti-slop review

Machine-generated prose fails in recognizable ways, and the problem is meaning and structure, not particular words. Do not just filter phrases. Ask of each sentence: does it give the reader information they need here?

| Pattern | Signal | Fix |
|---|---|---|
| Semantic padding | The sentence can be deleted without losing information | Delete it, or replace it with the specific fact it gestures at |
| Manufactured insight | Sounds profound but makes no testable claim ("the essence lies in the interplay of…") | State the concrete mechanism or remove it |
| Circular explanation | The conclusion is used as its own reason | Give the actual cause or evidence |
| Forced contrast | "not only… but also…", "không chỉ… mà còn…" used where a plain list would do | Use the plain statement |
| Narrative inflation | Routine work presented as an achievement ("significantly enhanced", "breakthrough") | Say what changed and by how much |
| Unnecessary qualification | Repeated hedges and disclaimers that carry no specific uncertainty | Keep one precise caveat where it applies |
| Excessive signposting | "In this section we will…", "Như sẽ trình bày dưới đây…" | Start with the content |
| Synthetic completeness | Sections added so the document looks complete (generic "Conclusion", "Future work", risk lists with no content) | Remove them, or fill them with real content |
| False precision | Numbers or percentages with no basis, weights presented as calibrated | Remove them or state their basis |
| Structural repetition | Several sections restate the same point | Keep it in the one place it belongs and refer to it |
| Jargon stacking | Several technical terms in one sentence where one plain clause would do | Unpack the sentence into one idea per clause |
| Meta-commentary | Agent instructions, process narration or compliance notes in the deliverable | Remove them; keep only substantive method or limitation statements |
| Condescension | Explaining basics the stated audience already knows | Cut to what this audience needs |
| Mechanical summary | Restating the paragraph or section just read | Delete it, unless it is a long document's executive summary |
| Artificial balance | Invented pros and cons, or "on the other hand" with nothing on the other hand | State the actual assessment |
| Labels instead of content | Headings or bold words that name a quality ("Key insight:", "Điểm đáng chú ý:") without delivering one | Remove the label and let the content stand |
| Uniform rhythm | Every paragraph the same length, every list three items, every sentence the same shape | Let the content set the length |

## Final pass

1. Read only the first sentence of each paragraph. Do they carry the argument? If not, reorder.
2. Delete every sentence whose removal loses nothing.
3. Check each adjective and adverb of degree: is there evidence for it?
4. Check each heading: does the section deliver what the heading promises?
5. Does anything in the document talk about the document or the writer instead of the subject?
